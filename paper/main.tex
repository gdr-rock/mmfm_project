\begin{abstract}
Long-horizon procedural planning from instructional videos requires both
high-level reasoning and perceptual grounding in the physical world. Recent
work on Vision Language World Models (\vlwm{}) demonstrates that coupling a
fast rollout generator (\sys{1}) with a deliberative critic (\sys{2}) yields
strong planning performance when trained at scale. However, \vlwm{} operates
purely in text space: its per-step latent alignment has not been studied under
resource-constrained settings or with publicly available datasets.

In this paper, we reproduce and extend the \vlwm{} planning architecture on
the \ct{} benchmark (18 tasks, 2{,}692 videos) using dramatically smaller
models: T5-small (60M) and PerceptionLM-1B with \lora{} as System-1, and
MiniLM+MLP or Llama-3.2-1B with \lora{} as System-2 critic. We integrate
\tj{} predictive video latents via a learned projection head and symmetric
InfoNCE loss, introducing a latent energy score that complements the critic
during plan selection. We additionally propose vision-grounded interpretation
generation using the PLM vision tower at inference time. We describe the
complete data pipeline, training methodology, dual-scale model design, and
evaluation protocol using VPA metrics (Success Rate, Mean Accuracy, Mean IoU),
providing a reproducible framework for latent-grounded procedural planning.
\end{abstract}

\section{Introduction}
\label{sec:intro}

Procedural planning—predicting the sequence of actions needed to accomplish a
high-level goal—is a fundamental capability for embodied agents and video
understanding systems. Given the observation ``the user has cracked eggs into a
bowl,'' a planning agent should predict subsequent steps such as \emph{add
flour}, \emph{stir batter}, \emph{pour onto griddle}, and so on.

The Vision Language World Model (\vlwm{}) of \citet{chen2025vlwm} addresses
this with a dual-system architecture inspired by Kahneman's
fast-and-slow reasoning:
\begin{itemize}[nosep,leftmargin=1.5em]
  \item \textbf{\sys{1}} is a fast rollout generator (PerceptionLM-8B) that
        produces candidate action sequences via next-token prediction.
  \item \textbf{\sys{2}} is a deliberative critic (Llama-3.2-1B) that scores
        candidate trajectories via a learned cost function, enabling
        tree-search planning.
\end{itemize}

Critically, \vlwm{} grounds System-1's per-step hidden states in video latents
(V-JEPA 2, \citealp{assran2025vjepa2}) through a contrastive InfoNCE
objective. This bridges the gap between text-only planning and physical
reality.

\paragraph{Challenges at smaller scale.}
\vlwm{} trains on 180{,}000 videos (5.7M step transitions) using 8B-parameter
models. Reproducing this on a publicly available dataset like \ct{}
\citep{zhukov2019crosstask} (2{,}692 videos, $\sim$18K transitions) requires
careful architectural adaptation to avoid overfitting while preserving the core
dual-system + latent-grounding design.

\paragraph{Contributions.}
We present a complete, reproducible framework that:
\begin{enumerate}[nosep,leftmargin=1.5em]
  \item Implements the full \vlwm{} dual-system planning pipeline on \ct{},
        providing two capacity tiers for each component:
        a \emph{lightweight} tier (T5-small, MiniLM+MLP) and a
        \emph{\vlwm{}-faithful} tier (PLM-1B + \lora{}, Llama-3.2-1B +
        \lora{}).
  \item Integrates \tj{} predictive video latents via a learned
        LatentProjectionHead and symmetric InfoNCE loss, with an energy-based
        plan scoring term: $E = \norm{\mathbf{z}_{\text{pred}} -
        \mathbf{z}_{\text{goal}}}_2^2$.
  \item Introduces zero-prefix planning (predicting from an empty observation
        history) and vision-grounded interpretation using the PLM vision tower
        at inference time.
  \item Provides a complete data pipeline from raw \ct{} annotations to
        train/val/test splits, along with evaluation on VPA metrics
        \citep{patel2023vpa}.
\end{enumerate}

\section{Related Work}
\label{sec:related}

\paragraph{Procedural planning from video.}
Procedural planning has been studied extensively in instructional video
understanding. Early methods use task graphs or structured models
\citep{zhukov2019crosstask,chang2020procedure}. More recent approaches frame
planning as text generation conditioned on visual observations
\citep{sun2022plate,zhao2022p3iv}. The VPA benchmark \citep{patel2023vpa}
standardized evaluation with Success Rate, Mean Accuracy, and Mean IoU metrics.

\paragraph{Vision Language World Models.}
\citet{chen2025vlwm} propose VLWM, a dual-system architecture where System-1
(PerceptionLM-8B) generates rollouts via next-token prediction on structured
trajectories $\langle \text{goal}, \text{interpretation}, A_0, \Delta S_0,
\ldots, A_n, \Delta S_n \rangle$, and System-2 (Llama-3.2-1B) scores
candidates via a learned cost function with ranking loss (Eq.~2).
Per-step hidden states are grounded in V-JEPA~2 latents via symmetric InfoNCE
(Eq.~3--4). VLWM achieves state-of-the-art on VPA benchmarks using 180K
training videos.

\paragraph{V-JEPA 2.}
\citet{assran2025vjepa2} introduce V-JEPA~2, a self-supervised video model
based on joint-embedding predictive architectures. The ViT-L encoder produces
1024-dimensional representations that capture spatiotemporal video semantics
without pixel-level reconstruction, making them well-suited as grounding
targets for language-based planning.

\paragraph{Parameter-efficient adaptation.}
Low-Rank Adaptation (\lora{}, \citealp{hu2022lora}) enables fine-tuning of
large language models with a fraction of the parameters. We apply \lora{} to
both the System-1 (PLM-1B) and Critic (Llama-3.2-1B) backbones with
$r=16, \alpha=32$, training $\sim$3M parameters while freezing the 1.2B base
model weights.

\subsection{System-1: Rollout Generator}
\label{sec:sys1}

System-1 takes a structured prompt containing the task goal, an interpretation
of the scene, and the observed action prefix, and generates the next $k$
action/state-change pairs as JSON:

\begin{quote}
\small
\texttt{Goal: Complete the task: Make Pancakes.}\\
\texttt{Interpretation: Task begins with cracking eggs \ldots}\\[4pt]
\texttt{Progress so far:}\\
\texttt{~~1) pour egg | Egg is now poured.}\\
\texttt{~~2) add flour | Flour is now added.}\\[4pt]
\texttt{Predict the next 3 step(s). Output JSON only:}
\end{quote}

\noindent The model outputs:
\begin{quote}
\small
\texttt{\{"next\_steps": [\{"action": "stir batter",}\\
\texttt{~~"state\_change": "Batter is now mixed."\}, \ldots]\}}
\end{quote}

\paragraph{Lightweight tier: T5-small.}
We fine-tune \texttt{google/flan-t5-small} (60M parameters) as a seq2seq
model. The encoder processes the structured prompt; the decoder generates the
JSON output autoregressively. This is appropriate for our data scale
($\sim$12K training samples).

\paragraph{VLWM-faithful tier: PLM-1B + \lora{}.}
Following the VLWM paper, we use PerceptionLM-1B \citep{meta2024plm} as a
causal language model. The structured prompt is the prefix; the model generates
the trajectory via next-token prediction (VLWM Eq.~1). We apply \lora{} with:
\begin{equation}
  r = 16, \quad \alpha = 32, \quad p_{\text{dropout}} = 0.05
  \label{eq:lora_config}
\end{equation}
targeting all attention and MLP projections (\texttt{q\_proj}, \texttt{k\_proj},
\texttt{v\_proj}, \texttt{o\_proj}, \texttt{gate\_proj}, \texttt{up\_proj},
\texttt{down\_proj}). This yields $\sim$3M trainable parameters out of 1.2B
total. The vision tower is frozen during training (text-only mode).


\subsection{Latent Grounding via InfoNCE}
\label{sec:grounding}

Following VLWM \S3.1.1 (Eq.~3--4), we ground per-step hidden states in
V-JEPA~2 video latents through a contrastive learning objective.

\paragraph{Latent Projection Head.}
A two-layer MLP projects decoder hidden states to the V-JEPA latent space:
\begin{equation}
  \mathbf{z}_{\text{text}} = \text{L2Norm}\Big(
    W_2 \cdot \text{GELU}(W_1 \cdot \mathbf{h}_{\text{step}})
  \Big)
  \label{eq:projection}
\end{equation}
where $\mathbf{h}_{\text{step}} \in \mathbb{R}^{d_{\text{dec}}}$ is the
decoder hidden state at each step boundary, $W_1 \in \mathbb{R}^{d_v \times
d_{\text{dec}}}$, $W_2 \in \mathbb{R}^{d_v \times d_v}$, and
$d_v = 1024$ is the V-JEPA dimension.

\paragraph{Symmetric InfoNCE.}
Given a batch of $N$ aligned (text, video) latent pairs
$\{(\mathbf{z}^t_i, \mathbf{z}^v_i)\}_{i=1}^N$, the loss is:
\begin{align}
  \mathcal{L}_{\text{t2v}} &= -\frac{1}{N}\sum_{i=1}^N \log
    \frac{\exp(\text{sim}(\mathbf{z}^t_i, \mathbf{z}^v_i)/\tau)}
         {\sum_{j=1}^N \exp(\text{sim}(\mathbf{z}^t_i, \mathbf{z}^v_j)/\tau)}
  \label{eq:t2v} \\
  \mathcal{L}_{\text{v2t}} &= -\frac{1}{N}\sum_{i=1}^N \log
    \frac{\exp(\text{sim}(\mathbf{z}^v_i, \mathbf{z}^t_i)/\tau)}
         {\sum_{j=1}^N \exp(\text{sim}(\mathbf{z}^v_i, \mathbf{z}^t_j)/\tau)}
  \label{eq:v2t} \\
  \mathcal{L}_{\text{latent}} &=
    \frac{1}{2}(\mathcal{L}_{\text{t2v}} + \mathcal{L}_{\text{v2t}})
  \label{eq:infonce}
\end{align}
with temperature $\tau = 0.07$. The combined training loss is:
\begin{equation}
  \mathcal{L} = \mathcal{L}_{\text{text}} + \alpha \cdot \mathcal{L}_{\text{latent}}
  \label{eq:combined}
\end{equation}

where $\mathcal{L}_{\text{text}}$ is the standard language modeling loss
(cross-entropy for seq2seq or NTP for causal LM), and $\alpha$ controls the
strength of latent grounding.


\subsection{System-2: Critic}
\label{sec:sys2}

System-2 scores trajectory quality for plan selection during inference. Given a
goal and a candidate trajectory, the critic outputs a scalar cost $C$. Lower
cost indicates a more plausible trajectory.

\paragraph{Lightweight tier: MiniLM + MLP.}
We use \texttt{all-MiniLM-L6-v2} (22M parameters, 384-dim) as the sentence
encoder. Each trajectory is serialized as:
\begin{quote}
\small
\texttt{[GOAL]~\{goal\}~[SEP]~\{step\_1\}~[SEP]~\{step\_2\}~[SEP]~\ldots}
\end{quote}
Mean pooling yields a 384-dim vector, passed through an MLP head:
\begin{equation}
  C = \text{MLP}_{384 \to 256 \to 1}(\text{MeanPool}(\text{Enc}(\mathbf{x})))
  \label{eq:critic_mlp}
\end{equation}

\paragraph{VLWM-faithful tier: Llama-3.2-1B + \lora{}.}
Following VLWM's critic design, we use Llama-3.2-1B with \lora{} (same
configuration as \Cref{eq:lora_config}). The last non-padding token's hidden
state ($\mathbb{R}^{2048}$) is mapped to a scalar cost via a linear head:
\begin{equation}
  C = W_c \cdot \mathbf{h}_{\text{last}} + b_c
  \label{eq:critic_llm}
\end{equation}
where $W_c \in \mathbb{R}^{1 \times 2048}$ is initialized to zero for stable
initial training.

\paragraph{Ranking Loss (VLWM Eq.~2).}
Both critics are trained with a margin-based ranking loss over trajectory
pairs. Given three signal types—\emph{good} (valid continuation),
\emph{bad} (distractor from another task), and \emph{shuffled} (randomly
reordered)—the loss enforces:
\begin{equation}
  \mathcal{L}_{\text{rank}} = \max(0, m + C_{\text{pos}} - C_{\text{neg}})
    + \lambda(C_{\text{pos}}^2 + C_{\text{neg}}^2)
  \label{eq:ranking}
\end{equation}
with margin $m=1.0$ and regularization $\lambda=0.01$. Three pairs are formed:
$(C_{\text{good}}, C_{\text{base}})$, $(C_{\text{base}}, C_{\text{bad}})$,
$(C_{\text{base}}, C_{\text{shuffled}})$.


\subsection{Goal Model}
\label{sec:goal}

A separate T5-small model jointly handles two tasks:
\begin{enumerate}[nosep,leftmargin=1.5em]
  \item \textbf{Goal prediction:} partial trajectory $\to$ goal text
        (18-class classification over task goals).
  \item \textbf{Goal + plan:} partial trajectory $\to$ JSON containing
        the inferred goal and remaining plan.
\end{enumerate}
Task type is embedded in the prompt instruction, enabling multi-task learning
with a single model.


\subsection{Inference: Plan Selection}
\label{sec:inference}

At inference, System-1 generates $K$ candidate plans via temperature sampling
($T = 0.8$). Each candidate is scored by:
\begin{equation}
  \text{Score}(\pi_k) = \alpha \cdot C(\text{goal}, \text{prefix} + \pi_k)
    + \beta \cdot E(\mathbf{z}_{\text{pred}}, \mathbf{z}_{\text{goal}})
  \label{eq:score}
\end{equation}
where $C$ is the critic cost, $E = \norm{\mathbf{z}_{\text{pred}} -
\mathbf{z}_{\text{goal}}}_2^2$ is the V-JEPA energy, and $\alpha, \beta$
control the trade-off. When V-JEPA latents are unavailable, $\beta = 0$
(critic-only reranking). The plan with the \textbf{lowest} score is selected.


\subsection{Vision-Grounded Interpretation}
\label{sec:vision_interp}

The interpretation line in the System-1 prompt summarizes the scene context.
During training, this is generated by a rule-based template system from
canonical step orderings. At inference time, we offer three sources:

\begin{enumerate}[nosep,leftmargin=1.5em]
  \item \textbf{CLI:} User provides \texttt{--interpretation} text directly.
  \item \textbf{JSONL:} Extracted from test samples (baked during data build).
  \item \textbf{Vision-grounded:} The PLM vision tower processes the
        \emph{first $N$ frames} of the video and generates interpretation
        text. This requires the \texttt{--frames} flag and a video path.
\end{enumerate}

For Option~3, we extract exactly the first $N$ frames (default $N=8$) using
\texttt{decord}, avoiding the uniform temporal sampling that would spread
frames across the entire video. The frames are passed as images (not video)
to the PLM processor to bypass the uniform sampling in
\texttt{BaseVideoProcessor.sample\_frames()}.


\subsection{Zero-Prefix Planning}
\label{sec:zero_prefix}

A practical deployment scenario requires planning from scratch (no observed
steps). We introduce zero-prefix samples into training data with probability
$p_{\text{zero}} = 0.15$ (configurable via \texttt{--zero\_prefix\_prob}).
The prompt format gracefully degrades:

\begin{quote}
\small
\texttt{Goal: Complete the task: Make Pancakes.}\\
\texttt{Interpretation: \ldots}\\[4pt]
\texttt{(No steps observed yet.)}\\[4pt]
\texttt{Predict the next 3 step(s). \ldots}
\end{quote}

\paragraph{Stage 1: State-Change Transitions (Script 04).}
We process raw \ct{} annotations (18 primary tasks, 105 steps, 2{,}692
videos) to build a transition-level CSV. For each annotated video, we extract
consecutive step pairs along with:
\begin{itemize}[nosep,leftmargin=1.5em]
  \item \textbf{Action descriptions:} verb-based templates (e.g., ``pour
        batter,'' ``flip pancake'').
  \item \textbf{State-change descriptions:} generated from a template engine
        with task-specific exact overrides and generic verb-based fallbacks
        (e.g., ``Batter is now poured into pan.'').
  \item \textbf{Temporal metadata:} start/end timestamps, canonical step
        ordering, and remaining plan suffix.
\end{itemize}
This yields 18{,}169 transition rows spanning all annotated segments.

\paragraph{Stage 2: Critic Dataset (Script 05).}
From the transitions, we build ranking triplets for critic training. Each
sample contains three trajectory variants:
\begin{itemize}[nosep,leftmargin=1.5em]
  \item $\text{traj}_{\text{good}}$: valid continuation from canonical order.
  \item $\text{traj}_{\text{bad}}$: steps drawn from a different task
        (cross-task distractor).
  \item $\text{traj}_{\text{shuffled}}$: correct steps in randomized order.
\end{itemize}
This produces 11{,}762 critic samples. Each sample also includes the base
trajectory for three-way ranking.

\paragraph{Stage 3: System-1 Dataset (Script 06).}
We construct prompt-completion pairs for the rollout generator. For each
transition subsequence, we create:
\begin{itemize}[nosep,leftmargin=1.5em]
  \item \textbf{Input:} structured prompt with goal, interpretation (rule-based
        from first/last canonical steps), and prefix of observed steps.
  \item \textbf{Output:} JSON \texttt{\{"next\_steps": [\ldots]\}} containing
        the next $k$ action/state-change pairs.
  \item \textbf{Zero-prefix:} with probability $p_{\text{zero}} = 0.15$, the
        prefix is empty.
\end{itemize}
The interpretation is generated by \texttt{make\_interpretation()}: a
deterministic function that produces text like ``\emph{Task begins with
cracking eggs and ends with serving pancakes.}'' from the canonical first
and last steps.

\paragraph{Stage 4: Goal Dataset (Script 07).}
We create two task types per trajectory subsequence: (a) goal prediction from
partial trajectory, and (b) joint goal + remaining plan prediction. This
yields 21{,}536 goal samples.

\paragraph{Stage 5: Train/Val/Test Split (Script 08).}
All four datasets are split at the \textbf{video level} using the official
\ct{} validation set. Test videos are stratified-sampled from the remaining
non-validation videos, ensuring no video appears in multiple splits.
\Cref{tab:dataset_stats} summarizes the final statistics.

\section{Experimental Setup}
\label{sec:experiments}

\subsection{V-JEPA Latent Extraction}

We extract V-JEPA~2 features using the ViT-L backbone. For each annotated
video segment, we:
\begin{enumerate}[nosep,leftmargin=1.5em]
  \item Download the video via \texttt{yt-dlp} (480p).
  \item Extract frames for each temporal segment using \texttt{decord}.
  \item Forward through the frozen V-JEPA~2 encoder.
  \item Mean-pool patch tokens to obtain $\mathbf{z} \in \mathbb{R}^{1024}$.
  \item Save per-segment \texttt{.pt} files under
        \texttt{data/crosstask/vjepa\_latents/\{task\_id\}/\{video\_id\}/}.
\end{enumerate}

\subsection{Evaluation Metrics}

Following the VPA benchmark \citep{patel2023vpa}, we evaluate on three
metrics:

\begin{itemize}[nosep,leftmargin=1.5em]
  \item \textbf{Success Rate (SR):} $\mathds{1}[\hat{\pi} = \pi^*]$ — exact
        sequence match between predicted and ground-truth plan.
  \item \textbf{Mean Accuracy (mAcc):} position-wise match fraction:
    \begin{equation}
      \text{mAcc} = \frac{1}{L}\sum_{i=1}^{L} \mathds{1}[\hat{a}_i = a_i^*]
      \label{eq:macc}
    \end{equation}
    where $L = \max(|\hat{\pi}|, |\pi^*|)$.
  \item \textbf{Mean IoU (mIoU):} set-level overlap:
    \begin{equation}
      \text{mIoU} = \frac{|\text{set}(\hat{\pi}) \cap \text{set}(\pi^*)|}{|\text{set}(\hat{\pi}) \cup \text{set}(\pi^*)|}
      \label{eq:miou}
    \end{equation}
\end{itemize}

\section{Analysis \& Discussion}
\label{sec:discussion}

\paragraph{Dual-system advantage.}
The System-1 / System-2 decomposition mirrors VLWM's core insight: fast
generation followed by deliberate evaluation. Even with smaller models, the
generate-then-rerank paradigm should provide measurable gains because the
critic operates on \emph{complete} trajectories, catching global coherence
issues that autoregressive generation misses step-by-step.

\paragraph{Latent grounding as regularization.}
The InfoNCE loss acts as a form of multimodal regularization—it constrains the
decoder's hidden state manifold to align with V-JEPA's video semantics. On
small datasets, this may serve a dual purpose: improving planning quality
\emph{and} preventing the text model from overfitting to surface-level action
patterns.

\paragraph{Scale gap considerations.}
With $\sim$100$\times$ less data than VLWM, we expect lower absolute metrics.
However, the \emph{relative} improvements (e.g., System-2 over System-1,
grounded over text-only) are the meaningful signal. If these hold, it validates
that the architectural principles transfer to resource-constrained settings.

\paragraph{Interpretation sourcing.}
A key difference from VLWM: our interpretation is an \emph{input} to the
model (provided at data-build time or inference time), whereas VLWM treats
interpretation as a \emph{model output} generated alongside actions. VLWM's
ablations (Table~6) show interpretation contributes $\sim$0.6\% to SR,
suggesting this design choice has minimal impact.

\paragraph{Vision-grounded interpretation at inference.}
Our Option~3 (PLM vision tower on initial frames) provides a bridge toward
VLWM's full multimodal pipeline. By extracting only the \emph{first} $N$
frames rather than uniformly sampling the entire video, we ensure the
interpretation reflects the starting state—consistent with the planning
scenario where the agent has only observed the beginning of the task.

\section{Implementation Details}
\label{sec:implementation}

\paragraph{Codebase.}
The complete pipeline is implemented in 13+ Python scripts under
\texttt{scripts/}, requiring only PyTorch, HuggingFace Transformers, PEFT,
sentence-transformers, and decord. No custom CUDA kernels are needed.

\paragraph{Reproducibility.}
All random seeds are fixed (default 42). Dataset splits are deterministic
given the same \ct{} annotation files. Model checkpoints, training logs, and
evaluation outputs are saved to standardized directory structures.

\paragraph{Hardware.}
Training was conducted on a single NVIDIA A100 (80GB) GPU.
\begin{itemize}[nosep,leftmargin=1.5em]
  \item T5-small System-1: $\sim$45 min (30 epochs, batch 16)
  \item PLM-1B + \lora{}: $\sim$3 hr (15 epochs, batch 8)
  \item MiniLM Critic: $\sim$20 min (30 epochs, batch 32)
  \item Llama Critic + \lora{}: $\sim$2 hr (15 epochs, batch 8)
  \item Goal Model: $\sim$30 min (20 epochs, batch 16)
  \item V-JEPA extraction: $\sim$varies by video count
\end{itemize}

\paragraph{Software.}
Python 3.10, PyTorch 2.1+, Transformers 4.40+, PEFT 0.10+,
sentence-transformers 2.7+, decord 0.6+.

\section{Limitations \& Future Work}
\label{sec:limitations}

\paragraph{Data scale.}
Our $\sim$12K training samples are two orders of magnitude smaller than
VLWM's 5.7M steps. While architectural insights transfer, absolute
performance will be limited. Scaling to Ego4D or COIN would provide a
fairer comparison.

\paragraph{V-JEPA integration.}
Our V-JEPA extraction pipeline provides a working interface, but falls
back to random features if the V-JEPA~2 repository is unavailable. A tighter
integration (e.g., end-to-end differentiable frame encoding) would
strengthen the latent grounding signal.

\paragraph{Energy as heuristic.}
The energy term $E = \norm{\mathbf{z}_{\text{pred}} - \mathbf{z}_{\text{goal}}}_2^2$
uses direct latent lookup. A learned latent dynamics model that
\emph{predicts} $\mathbf{z}_{\text{next}}$ from text would make this a true
world model component.

\paragraph{Video availability.}
CrossTask videos are hosted on YouTube; some have been deleted since the
dataset was published. Our pipeline handles failures gracefully (skip and
continue), but this reduces effective dataset size.

\paragraph{Interpretation fidelity.}
The rule-based interpretation generator is deterministic and somewhat
formulaic. VLWM generates interpretation as model output, allowing richer,
context-dependent scene descriptions. Our vision-grounded Option~3 partially
addresses this gap.

\section{Conclusion}
\label{sec:conclusion}

We presented a complete framework for latent-grounded procedural planning that
reproduces and extends the VLWM dual-system architecture on the CrossTask
benchmark. Our implementation provides two model tiers—lightweight (T5-small,
MiniLM+MLP) and VLWM-faithful (PLM-1B+\lora{}, Llama-3.2-1B+\lora{})—with
optional V-JEPA~2 latent grounding via symmetric InfoNCE.

The key architectural insight is that the dual-system generate-then-rerank
paradigm, combined with multimodal latent alignment, provides a principled
framework for procedural planning even at reduced scale. The energy-based
scoring with V-JEPA latents offers an orthogonal signal to the learned
critic, and the vision-grounded interpretation bridges toward fully
multimodal planning at inference time.

Our complete data pipeline, training scripts, and evaluation protocol are
publicly available, providing a reproducible foundation for future work on
latent-grounded video planning.
